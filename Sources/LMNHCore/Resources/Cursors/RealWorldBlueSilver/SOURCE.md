# RealWorld 3D Blue-Silver Cursor Set

Source: http://www.rw-designer.com/cursor-set/rw-blue-silver

Author: Vlasta

License: Creative Commons Attribution

The original download includes `RWArrow.cur`, `RWAppStarting.ani`, and `RWBusy.ani`.
The PNG files in this directory are extracted frames used by the macOS overlay
renderer, because AppKit does not load Windows `.ani` cursor animations directly.
